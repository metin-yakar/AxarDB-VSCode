# Changelog

All notable changes to the **AxarDB for Visual Studio Code** extension will be documented in this file.

## [0.1.0] - 2026-10-23

### Initial Release
- **Connection Management:** Multi-server support with SecretStorage credentials and ping health status.
- **Connections View:** Activity Bar webview with live search and 7 distinct category accordions (DB, SYS, LOG, MEMORY, BULK, VIEW, TRIGGER).
- **Data Panel:** Tabular editable DataGrid, JSON card mode, and resizable side panel with syntax highlighting.
- **Query Editor:** CodeLens and Ctrl+Enter execution for `.axar.js` files with result piping.
- **Export & Backup:** Streaming export for JSON, JSONLines, and RFC 4180 CSV formats.
- **Log Viewer:** Integrated system and collection-filtered log viewer.
- **Context Menus:** Full set of native VS Code context menus for servers, categories, collections, and table rows.
